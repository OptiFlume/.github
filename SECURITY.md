# Security

OptiFlume runs on the user's Mac and never sends prompts or code anywhere. How it is built, signed
and updated, and what leaves the Mac, is described at https://optiflume.ai/security.

**Reporting a vulnerability:** email security@optiflume.ai. Please do not open a public issue.
Include the OptiFlume version (`optiflume status` prints it), macOS version, the tool (Cursor, Claude Code
or Codex) and steps to reproduce. We acknowledge reports within two business days and tell you when
the fix ships; fixes go out through the normal update channel.

Secret scanning and push protection are on for every repository in this organization.

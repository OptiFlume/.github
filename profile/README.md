# OptiFlume

**Model routing, context management and guardrails for AI coding, in Cursor, Claude Code and Codex.**

OptiFlume runs on your Mac beside the tool you already use. It picks the model and effort for each
prompt and shows every switch with a reason, carries a long session's goals and decisions through
compaction and model switches, and asks before secrets reach the model or a destructive command runs.
Nothing goes through a proxy; the decision is made on your machine.
